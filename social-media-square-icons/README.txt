# Square social media icon assets

All PNG images: 512 × 512 pixels, RGBA, square canvas. SVG versions included.
Files: facebook, threads, linkedin, x, instagram.

Icons are simplified UI-friendly renditions built using publicly available vector outlines.
Facebook, Instagram, Threads, and X outlines: Simple Icons (CC0 icon artwork; brand marks are trademarks).
LinkedIn outline: Font Awesome Free 7.3.1 by Fonticons Inc., CC BY 4.0 (https://fontawesome.com/license/free).
Square background colors, padding, and gradient treatments were added to make a consistent app icon set.
This package is not an official brand asset download. For publication/distribution, check approved marks and each brand's latest guidelines:

Facebook: https://www.meta.com/brand/resources/facebook/logo/
Threads: https://www.meta.com/brand/resources/threads/
LinkedIn: https://brand.linkedin.com/in-logo
X: https://about.x.com/en/who-we-are/brand-toolkit
Instagram: https://www.meta.com/brand/resources/instagram/instagram-brand/

Threads branding changed in May 2026. The included Threads vector comes from the current Simple Icons repository and may not exactly match Meta's current official Threads asset. If shipping, replace with the Meta-provided icon.
